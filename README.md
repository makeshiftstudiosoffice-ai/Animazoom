# AnimaZoom

**AnimaZoom** não é filtro, não é editor, não é mais um app de câmera.  
É um **estúdio criativo portátil**, autoral e inédito, que transforma gravações em obras multimídia tipográficas e visuais em tempo real.

## 🚀 Features
- 🎥 Pipeline técnico robusto (CameraX + MediaRecorder)
- 🖋️ Motor artístico autoral (papel vegetal, tipografia Olivetti Noir, palavras aleatórias)
- 👻 Identidade visual inédita (logo fantasma + carimbo BRAZI Studios)
- 🔒 Offline e transparente (sem Firebase, sem anúncios, sem coleta de dados)
- 🌍 Integração prática (cockpit social, envio direto para WhatsApp, cofre de vídeos)

## 🎯 Filosofia
Este projeto nasceu da inquietação criativa:  
> “Se não existe, por que não? Então eu faço.”  

Não busca startup, não busca lucro. É uma **bomba criativa** solta no mundo: quem quiser testa, expande, adapta.  
Cada gravação vira uma obra multimídia com identidade própria.

## 📦 Instalação
1. Clone este repositório.
2. Abra no Android Studio.
3. Compile e rode em dispositivo físico (necessário acesso à câmera).
